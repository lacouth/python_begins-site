    Lista 13 · Decompor e testar¶

    A última lista do semestre. O formato é o mesmo da Lista 12 — função com testes prontos no fim do arquivo —, mas alguns exercícios agora pedem duas funções no mesmo arquivo, uma chamando a outra: é a decomposição do Capítulo 13.

    Lembre-se do escopo: uma variável criada dentro de uma função não existe fora dela — quem quiser usar o resultado precisa do return. E, se um teste falhar, o AssertionError aponta a linha exata; leia com calma antes de mexer na função.

    Baixar o caderno

    Como esta lista funciona

    Abra o caderno no Colab e salve uma cópia no seu Drive antes de começar (Arquivo → Salvar uma cópia no Drive). Sem isso, você perde o que escrever.

    Nos exercícios com célula de teste, escreva a solução no lugar do # TODO e rode a célula de teste logo abaixo. Ela mesma diz o que passou e o que falhou; se aparecer AssertionError, a linha apontada é o caso que a sua solução ainda não atende. Não altere a célula de teste.

    O código de cada exercício também está aqui embaixo, caso você prefira colar num editor local.

    Parte A · no papel¶

    Faça esta parte antes de ligar o computador

    Escreva a resposta no caderno, depois rode para conferir. Prever e errar ensina; rodar primeiro e ler a saída, não.

    No papel, antes do computador.

    A1. Rastreie as funções. Complete a tabela com o que cada chamada devolve.

    def calcula_desconto(preco, percentual):
    return preco * percentual / 100


def preco_final(preco, percentual):
    desconto = calcula_desconto(preco, percentual)
    return preco - desconto


preco_final(200, 10)
    Chamada Devolve
    calcula_desconto(200, 10)
    preco_final(200, 10)

    A2. Escopo. O que este programa imprime, ou qual erro ele dá? Justifique em uma frase.

    def calcula_desconto(preco, percentual):
    desconto = preco * percentual / 100
    return desconto


calcula_desconto(200, 10)
print(desconto)

    A3. Passa ou falha? Para cada assert abaixo, diga se ele passa em silêncio ou levanta AssertionError. Use esta função:

    def dobro(numero):
    return numero * 2
    Assert Passa ou falha?
    assert dobro(4) == 8
    assert dobro(0) == 0
    assert dobro(4) == 9
    assert dobro(-2) == -4

    A4. Ache o defeito. Estas duas funções deveriam trabalhar juntas, mas preco_final está errado — e o teste de calcula_desconto, sozinha, passaria sem denunciar nada. Qual é o defeito?

    def calcula_desconto(preco, percentual):
    return preco * percentual / 100


def preco_final(preco, percentual):
    return preco - (preco * 10 / 100)
