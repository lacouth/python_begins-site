    Lista 12 · Funções¶

    Esta é a primeira lista em que você escreve funções, no formato de Python para Telecomunicações: cada exercício abaixo é uma função, com um bloco de testes que já vem pronto no fim do arquivo. Se aparecer a mensagem de sucesso, está certo; se aparecer AssertionError, a linha apontada é o caso que a sua função ainda não atende.

    O assunto é o do Capítulo 12: def, parâmetro, argumento e return. Antes de entregar qualquer exercício, pergunte-se: minha função devolve o valor, ou só mostra na tela? É o defeito mais comum desta lista — a função que imprime o número certo e esquece o return.

    Baixar o caderno

    Como esta lista funciona

    Abra o caderno no Colab e salve uma cópia no seu Drive antes de começar (Arquivo → Salvar uma cópia no Drive). Sem isso, você perde o que escrever.

    Nos exercícios com célula de teste, escreva a solução no lugar do # TODO e rode a célula de teste logo abaixo. Ela mesma diz o que passou e o que falhou; se aparecer AssertionError, a linha apontada é o caso que a sua solução ainda não atende. Não altere a célula de teste.

    O código de cada exercício também está aqui embaixo, caso você prefira colar num editor local.

    Parte A · no papel¶

    Faça esta parte antes de ligar o computador

    Escreva a resposta no caderno, depois rode para conferir. Prever e errar ensina; rodar primeiro e ler a saída, não.

    No papel, antes do computador.

    A1. Rastreie as chamadas. Complete a tabela com o que cada chamada imprime.

    def linha_fatura(servico, valor):
    print(f"{servico}: R$ {valor:.2f}")

linha_fatura("Telefone", 45.5)
    Chamada O que imprime
    linha_fatura("Internet", 99.9)
    linha_fatura("Telefone", 45.5)

    A2. Parâmetro ou argumento? Para cada item abaixo, diga se ele é um parâmetro ou um argumento.

    def calcula_total(preco, quantidade):
    return preco * quantidade


calcula_total(9.90, 3)
    Item Parâmetro ou argumento?
    preco, na linha do def
    quantidade, na linha do def
    9.90, na chamada
    3, na chamada

    A3. A armadilha do capítulo. O que este programa imprime, linha por linha?

    def dobro(numero):
    print(numero * 2)


resultado = dobro(5)
print(resultado)
    Linha O que imprime
    resultado = dobro(5)
    print(resultado)

    resultado guardou o quê, de fato? Por que a função parece ter funcionado, mesmo estando incompleta?

    A4. Conserte. Esta função devia devolver o dobro do valor recebido, mas todo teste falha, sempre comparando com None. Reescreva-a corretamente, no caderno.

    def dobro(numero):
    numero * 2

    A5. Quantos argumentos? Esta função tem dois parâmetros:

    def custo_total(preco_unitario, quantidade):
    return preco_unitario * quantidade

    Para cada chamada abaixo, diga se ela funciona ou dá erro — e, se der erro, qual:

    Chamada Funciona ou dá erro?
    custo_total(9.90, 3)
    custo_total(9.90)
    custo_total(9.90, 3, 1)
